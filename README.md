Preprocesamiento de Datos

Cultura Digital y Sociedad - Actividad Autónoma 3: Herramientas y Metodologías en Ciencia de Datos.

Objetivo:

Aplicar de manera práctica el uso de github y git, para poder hacer una correcta gestión de versiones, además del uso de pandas en python para normalizar, codificar variables categóricas, eliminación de valores duplicados y procesar valores nulos.

Organización de carpetas:

preprocesamiento-ciencia-datos/

 ┣ .github/                 #Contiene el archivo de automatización (python-check.yml) para GitHub Actions.
 ┃ ┗ workflows/
 ┃   ┗ python-check.yml   
 ┣ .gitignore               #Archivo que le indica a Git qué archivos basura debe ignorar.
 ┣ preprocesamiento.py      #Script principal de Python que contiene la función para limpiar los datos.
 ┗ README.md                #Este archivo, que explica de qué trata el proyecto.
